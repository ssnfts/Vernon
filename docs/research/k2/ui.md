# k2 review: UI area (app shell, vernon-render)

Vetted against: CLEAN_ROOM.md, `docs/specs/ui-dcc-conventions.md` (spec), Vernon API (`Geometry`, `Report`/`Metric`, `NodeTypeInfo`/`NodeOp`/`CookContext`, `ParamSpec`/`ParamKind`/`ParamValue`/`Params`, `Data`/`DataKind`), `cargo info`, the local egui 0.32.3 / egui-wgpu / egui_extras / egui_kittest sources in the cargo registry, and 5 web searches (section 3). k2 never saw the code, so many of its sketches duplicate things Vernon already has (node registry, cache key, ParamSpec schema, Report gating). Not read, so not judged: the `Graph` struct in vernon-graph and the vernon-render sources (only its Cargo.toml was read).

## 1. Summary

1. Keep k2's UI skeleton (quad viewports, command panel, schema-driven Modify tab, ray-cast nav cube, playback from wall-clock, coalescing event queue). Most of it already matches the spec.
2. Reject everything that duplicates Vernon's graph: a separate modifier trait/registry/enabled flags, keyframe curves (out of scope in spec section 1), and in-process Python listeners (pyo3 links CPython, auto-run is a code-execution hole). The stack is a projection of the node chain (spec 3.7).
3. Hard conflicts with CLEAN_ROOM: the About dialog naming the vendor, `resvg 0.37` (MPL-2.0), hard-coded `#FFB400` icon strokes, OpenCascade linked in-process (C++).
4. Maths checked: WCAG numbers in k2 are right, but "all pairs meet AA" is false for more pairs than disabled text; nav cube "edge = isometric" is wrong (corner is); milestone sum is 14, not 13; 25% of 1120 is 280 (the conflict is real).
5. Biggest wins for Vernon: bounded/coalesced bus with generation-tagged cooks, egui_extras SVG icons as white masks tinted by tokens, kittest tolerance snapshots, a unit-test that scans every `NodeTypeInfo` for vendor names, `versioned + #[serde(default)]` JSON files.

## 3. Bugs and hazards (k2's claims, and ones k2 missed)

Legal searches (US law, general area; not legal advice). VERIFIED by search: Lotus Dev. Corp. v. Borland Int'l, 49 F.3d 807 (1st Cir. 1995), aff'd by an equally divided Court, 516 U.S. 233 (1996): command menu hierarchy held an uncopyrightable method of operation under 17 U.S.C. 102(b). Apple Computer v. Microsoft, 35 F.3d 1435 (9th Cir. 1994): GUI copyright; thin protection after filtering, decided Sep 1994 (holding detail from secondary summaries; opinion text not read). Wal-Mart Stores v. Samara Bros., 529 U.S. 205 (2000): product design trade dress needs secondary meaning. Google LLC v. Oracle America (U.S. 2021): fair use, copyrightability left undecided; the "593 U.S. 1" reporter cite was not confirmed (UNVERIFIED). TrafFix v. Marketing Displays, 532 U.S. 23 (2001), functionality: UNVERIFIED (search returned nothing on it). OCCT: LGPL-2.1 plus Open CASCADE Exception 1.0 for 6.7.0 and later, per SPDX (VERIFIED); other jurisdictions (UK/EU) differ and are not covered.

Hazards:
- **WCAG blanket claim wrong in more places than disabled text.** Computed on k2's palette: text_disabled 3.12 (primary), 2.81 (panel), 2.51 (hover), 2.10 (pressed); error text 4.78 (panel) but 4.27 (hover) and 3.57 (pressed), below 4.5 as text; accent_dark on pressed 4.17; text_secondary on pressed 4.65 passes; divider 1.6 to 1.08 (decorative, exempt). Spec 3.12 numbers re-computed on #262626 and all match (12.13, 7.63, 9.02, 6.73, 4.09, 4.38).
- **About dialog naming a vendor** breaks CLEAN_ROOM (U62). **resvg 0.37 is MPL-2.0** (U31). **`#FFB400` strokes** break tinting (U29).
- **Events cannot be serde as sketched**: `Data` is not `Serialize`; `Arc<T>` serde needs the `rc` feature (U04).
- **`ParamValue` is `serde(untagged)`**: Str/Path/Enum are indistinguishable by value; JSON NaN/inf becomes null; Int vs Float depends on the textual form. Widgets must come from `ParamSpec.kind`; validate finiteness at the command boundary.
- **`register_native_texture` needs `Rgba8Unorm`** (egui-wgpu 0.32.3 docs): an sRGB target format will render too bright/dark. Make vernon-render's offscreen format a tested constant.
- **Workspace `rust-version = "1.80"` is wrong**: egui 0.32.3 and egui-wgpu 0.32.3 declare 1.85 (`cargo info`). Bump to 1.85.
- **Latest crates need a newer egui**: egui_kittest 0.37 (Rust 1.95), egui_tiles 0.18 and egui_dock 0.21 (Rust 1.95), egui_plot 0.38 (1.95), egui_commonmark 0.26 (1.95). For egui 0.32.3 use egui_kittest 0.32.3, egui_tiles 0.13.0 or egui_dock 0.17.0; a probe project resolved either with exactly one egui (0.32.3).
- k2's popup fix is deprecated (U46); k2's `from_id_source` and `Frame::none` are deprecated (U23); `ctx.set_theme` takes `ThemePreference` (U35). k2's "no Tree widget" and "no accessibility_names" are correct (U24, U38).
- Nav cube "edge = isometric" is wrong (U18); 3x3 grid cannot address 26 regions (U19). Lock Viewports as described would break orthographic tiles (U12).
- Playback stress at real time is 333 s (U49). Cache fingerprint: do not hand-add the frame downstream (U45).
- k2's three contradictory thread placements for the dispatcher make the "no race" claim unprovable; replace with generation-tagged snapshots (U67).
- Not verified by me: PyO3 API renames (U53), `cargo deny --all` (U59), svglint (Node tool, not on crates.io), any behaviour of the unreviewed `Graph` and vernon-render sources.
