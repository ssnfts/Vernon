# Vernon agent guide

Generated by `vernon-cli agent-guide`; do not edit by hand.

Vernon is a node-graph 3D app for a car body-kit pipeline: scan, clean, surface, split/print, CFD, FEA, solar, performance. You build a graph with tools, cook it, and read the reports. 201 node types (3 placeholders that say so in a warning).

## Working loop

1. `list_nodes(stage)` then `describe_node(type_id)` for ports, parameter ranges, units and options.
2. `add_node`, `set_param`, `connect` (by name; ports by name or index). Errors tell you the valid names and ranges.
3. `cook(node)`, then `read_report`, `get_metric`, `list_gates`, `measure_geometry`.
4. Wrap a whole task in `begin_group` / `end_group` so one `undo` reverts it. `save_graph` / `load_graph` use relative `.vrn` paths in the work folder only.

## Conventions

- Lengths are millimetres, Z is up, physics in SI with the unit shown in each parameter.
- Geometry attributes: point `N`, `Cd`, `uv`, `dist`; face `N`, `part`, `temp_c`, `Cp`.
- Wire kinds: Geometry, Report, File, Json. A Report output carries metrics for the next stage.
- File parameters must be relative paths without `..`.
- Nodes that drive an external program (solver, slicer) only write input files unless their `run` switch is on. Leave it off unless the user asked; it resets after each cook.

## Gates

A metric with a limit is a gate: it passes when the value is on the right side of the limit (`lower_is_better` says which). A failing gate or an error note fails the report and the stages after it should not be trusted. A failure the scene lists under a node's `expect_fail` is reported as expected. `cook` returns `failed_gates` with value, limit and margin; fix the cause (parameters, upstream geometry), re-cook, do not edit limits to make a gate pass. Gate nodes: `clean.tolerance_gate`, `print.build_fit`, `print.heat_margin`, `solar.hdt_check`, `perf.validation_gate`, `perf.gate_summary`.

## Recipes

`add name = type {params}`; `wire out[.port] -> in[.port]` is `connect`.

### 1. Scan, align, deviation

```
add ref = geo.car_panel
add scan = geo.noise {"sigma":0.2}
wire ref -> scan
add pre = clean.auto_prealign
wire scan -> pre.moving
wire ref -> pre.reference
add icp = clean.icp_align
wire pre.geometry -> icp.moving
wire ref -> icp.reference
add dev = clean.mesh_distance
wire icp.geometry -> dev.compared
wire ref -> dev.reference
add stats = clean.deviation_stats {"tolerance":0.5}
wire dev.geometry -> stats.geometry
add gate = clean.tolerance_gate {"tolerance":0.5}
wire stats.stats -> gate.stats
```
cook gate; list_gates. With a real scan, replace ref/scan by capture.import_scan (set path, unit).

### 2. Split for the print bed

```
add body = geo.car_panel {"thickness":4}
add split = print.smart_partition {"printer":"bed_350"}
wire body -> split.mesh
add fit = print.build_fit {"printer":"bed_350"}
wire split.parts -> fit.parts
```
Split needs a closed solid (thickness above 0). cook fit; read_report fit. Parts that do not fit the bed fail the gate: split more or change printer.

### 3. CFD case setup (files only)

```
add body = geo.car_panel
add prep = cfd.vehicle_prep
wire body -> prep.body
add tunnel = cfd.tunnel_domain
wire prep.reference -> tunnel.reference
add mesh = cfd.mesh_setup
wire tunnel.domain -> mesh.domain
wire prep.vehicle -> mesh.vehicle
add case = cfd.case_setup {"u_ms":30}
wire tunnel.domain -> case.domain
wire prep.reference -> case.reference
```
cook case. Nodes only write input files; meshing or solving needs run=true and an installed program, which you must not enable unless asked.

### 4. Hot-day heat check

```
add body = geo.car_panel
add hour = solar.design_hour
add bal = solar.surface_balance
wire body -> bal.mesh
wire hour.weather -> bal.weather
add hdt = solar.hdt_check {"material":"ASA"}
wire bal.mesh -> hdt.mesh
```
cook hdt; read_report hdt. A negative worst margin means the material softens.

### 5. Clean a mesh

```
add body = geo.car_panel
add fill = clean.fill_boundary_holes
wire body -> fill.mesh
add smooth = clean.smooth_mesh {"iterations":10}
wire fill.geometry -> smooth.mesh
add dec = clean.decimate {"ratio":0.5}
wire smooth.geometry -> dec.mesh
```
measure_geometry dec: check watertight and that size_mm did not change.

### 6. Flatten a panel

```
add body = geo.car_panel
add cut = flatten.seam_cut
wire body -> cut.mesh
add flat = flatten.conformal_map {"max_strain_pct":5}
wire cut.mesh -> flat.mesh
add strain = flatten.strain_report
wire flat.mesh -> strain.mesh
wire flat.pattern -> strain.pattern
```
cook strain; read_report strain. Strain above the limit means add seams.
